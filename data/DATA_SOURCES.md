# Data Sources

## Synthetic Samples (Current — Pipeline Development Only)
Generated by `src/utils/generate_samples.py`
These approximate the frequency profiles of real alarm calls but are NOT
suitable for training a production model.

## Real Data Sources (Replace synthetic with these)

### Xeno-Canto (xeno-canto.org)
- Sambar deer: search "Rusa unicolor", filter type: "alarm" or "call"
- Langur: search "Semnopithecus", filter type: "alarm"
- Chital: search "Axis axis", filter type: "alarm"
- Tiger: search "Panthera tigris"
- License: Creative Commons (check per recording)

### Macaulay Library (macaulaylibrary.org)
- Cornell Lab of Ornithology's collection
- Search by species scientific name
- Higher quality recordings, stricter licensing

### Field Recordings
- AudioMoth deployments in Indian tiger reserves
- Requires forest department permission
- Most valuable for training — real forest acoustic conditions
